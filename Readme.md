# Job Application Tracker + Analytics

A full-stack web application that helps job seekers manage job applications, track interview preparation, and analyze their placement progress.

## 🚀 Live Demo

[Live Application](https://job-application-tracker-sandy-eta.vercel.app)

## ✨ Features

- JWT-based user authentication
- Secure password hashing with bcrypt
- Job application CRUD operations
- Search, filter, and sort applications
- Application status tracking
- Interview preparation tracker
- DSA topic-wise progress tracking
- Application analytics dashboard
- Application conversion metrics
- Responsive design for desktop and mobile
- RESTful backend API
- MongoDB-based persistent data storage

## 🛠️ Tech Stack

### Frontend

- React
- React Router
- Axios

- Vite

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

### Deployment

- Render
